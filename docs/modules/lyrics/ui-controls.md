# 歌词 UI 控件

当前歌词 UI 位于 `CorePlanetMusicPlayer6/Controls/Dev`，包括滚动歌词控件和歌词编辑控件。它们用于开发阶段验证完整交互，尚未集成到正式播放页面。

## 滚动歌词控件

[`LyricControl`](../../../CorePlanetMusicPlayer6/Controls/Dev/LyricControl.xaml) 展示播放器当前首选歌词。

### 加载流程

控件加载后：

1. 获取播放、音乐查询和歌词服务。
2. 订阅当前歌曲变化和播放位置变化事件。
3. 并行加载歌曲资料与首选歌词。
4. 将歌词行转换为 `LyricLineViewModel`。
5. 按当前播放位置立即定位一次。

切歌会清空旧歌词并重新加载。加载过程中使用生命周期和加载版本号，过期的异步结果不会更新新歌曲界面。

### 播放位置同步

控件使用 200 毫秒的 `DispatcherTimer` 调用播放服务的 `RefreshPosition`，同时监听位置变化事件。

当前行通过二分查找确定。播放位置仍在同一歌词行时不会重复更新高亮或发起滚动。

### 视觉状态

`LyricLineViewModel` 控制当前行状态：

- 当前行透明度为 `1.0`。
- 非当前行透明度为 `0.2`。
- 翻译为空时隐藏翻译文本块。
- 原文和翻译都支持自动换行。

### 自动滚动

当前歌词变化且自动跟随启用时：

1. 使用 `ScrollIntoView` 生成虚拟化列表项容器。
2. 等待低优先级 UI 调度。
3. 读取列表项的实际高度和位置。
4. 将歌词中心定位到视口高度约 40% 的位置。

定位基于实际行高，因此翻译换行不会破坏滚动位置。

滚动任务使用独立版本号。新的歌词行、手动操作、切歌或控件卸载都会使旧滚动失效。

### 手动浏览与跳转

- 用户按下、触摸或使用滚轮时，自动跟随暂停。
- 暂停跟随后，当前歌词仍继续高亮。
- 顶部工具栏可以恢复自动跟随。
- 点击歌词行会调用播放服务跳转到对应时间，并恢复自动跟随。

## 歌词编辑控件

[`LyricEditControl`](../../../CorePlanetMusicPlayer6/Controls/Dev/LyricEditControl.xaml) 用于编辑当前播放歌曲的歌词。

### 来源选择

顶部 `ComboBox` 展示全部有效来源：

- 应用缓存
- 外部歌词及其相对路径
- 内嵌歌词
- 在线歌词

播放器当前首选项带有“播放器首选”标记。切换选项只改变编辑器的当前文档，不会改变全局读取顺序。

存在未保存修改时，切换来源前会要求用户确认。

### 编辑状态

文本变化后设置脏状态。以下操作会保护未保存内容：

- 重新加载
- 切换歌词来源
- 当前播放歌曲变化

保存成功后，编辑器重新加载所有来源，并尽量继续选中刚刚保存的目标。保存非首选来源时，状态栏会说明播放器仍然优先使用哪一个来源。

### 工具栏命令

- 重新加载
- 保存
- 写入内嵌歌词
- 保存至应用中
- 恢复来源歌词

“恢复来源歌词”仅在当前文档是应用缓存时可用。外部来源可以使用额外命令写入音频标签或保存为应用缓存。

## 生命周期安全

两个控件都会在 `Unloaded` 时：

- 停止计时器。
- 解除播放服务事件订阅。
- 增加生命周期和请求版本号。
- 清除服务和当前文档引用。

异步操作在应用结果前会重新检查控件生命周期、歌曲 ID、服务实例和请求版本，避免快速切歌或页面离开后的过期更新。
